# Schema Tools — データエディターとコマンドパレット

Schema Tools は作者向けの二つのウィンドウで、どちらも各 MOD がスキーマとして同梱する記述から丸ごと作られます（Schemas MOD を参照）:

- **データエディター**は、記述されたどの種類のエンティティでも——ステータス、クラス、アイテム、キャラクター、戦闘アクション、ショップ、レシピ——フォームで編集します；
- **コマンドパレット**はフォームからシナリオの行を書き、検査してからシナリオエディターに入れます。

どちらのウィンドウも、種類や行動を前もって知りません: 読み込まれた MOD が記述したものがそこに現れます。どちらもゲームのツールバーのツールボックスから、ゲームの実行中に開きます。

## データエディター

上で MOD、左でデータの種類、中央で項目を選ぶと、右にフォームがあります。RPG Plus の Classic RPG Rules の鉄の剣はこうです:

![データエディター: MOD classic_rpg_pack、左に種類（rpg_tileset 10、Stats 11、Archetypes 3、Equipment slots 3、Items 20、Characters 5、Battle actions 7、Shops 1、Crafting station 1、Recipe 3）、中央にその九つのアイテムと Iron sword の選択、右にフォーム: Id、Name、Description は七つの言語それぞれのテキスト、Cost 30、Picture、Item types TargetUsed、Item action action/equip、Equip type sword、Attack ステータス上の特性。](assets/data-editor-item.jpg)

フォームは複数の MOD のフィールドを一つにまとめます: Id、名前、説明、価格、画像、アイテムの種類とアイテムの行動は Items Engine が記述し、**Equip type**、**Traits** リスト（ステータスと量）、装備できるクラスは Equipment が足します。二つの MOD が記述する種類でも、フォームは一つです。

- **テキスト**（`Name`、`Description`）は翻訳キーと MOD の言語ごとの行として表示され、MOD 自身のローカライズファイルに書き込まれます。
- **参照**（ステータス、アイテム、クラス）は、ゲームが知っている id の一覧です。
- **リスト**（traits など）は要素ごとにカードを持ち、それぞれに独自のフィールドがあります。
- どのスキーマにもないプロパティは保持され、その他のフィールドとして JSON で表示されます。

ツールバー: **新規**（Ctrl+N）はスキーマの既定値で項目を追加し、**コピー**（Ctrl+D）は選択項目を複製し、**削除**は先に確認し、**元に戻す**/**やり直す**（Ctrl+Z / Ctrl+Y または Ctrl+Shift+Z）は変更をたどり、**保存**（Ctrl+S）は変更したファイルだけを LF 改行で書き込みます。保存した直後から実行中のゲームに反映されます: 新しいアイテムは再起動なしで渡して装備できます。

上の一覧には書き込める MOD だけが並びます。MOD の項目はその MOD 自身のファイルにあるもので、他の MOD のエンティティを変えるにはその MOD で編集します。

## コマンドパレット

左で行動かコマンドを選び（「ダメージ」「アイテム」「check」などの語で検索できます）、フォームを埋めると、その下に行が現れます:

![Change a stat for good を選んだパレット: 「MOD stats_base が記述」、Stat Strength · str、Value 2、Who は空、行「action stat.add stat=str value=2」、「行に問題なし」。](assets/palette-line.jpg)

行は入力しながら、Validator と同じ規則で検査されます。ステータス名の打ち間違い:

![ステータスを strenght にした同じフォーム: 行「action stat.add stat=strenght value=2」とエラー「'stat.add': 'stat' が指すステータス 'strenght' は、読み込まれたどの MOD も定義していない」。](assets/palette-misspelt.jpg)

**挿入**は、シナリオエディターで開いているシナリオのカーソル位置に行を入れ、**コピー**はクリップボードに入れます。RPG Plus の予言者のシナリオに挿入したあと:

![シナリオエディターで変更ありと印された seer.scenario（seer *）: 2 行目は「action stat.add stat=str value=2」になり、予言者の挨拶と幸運の判定のあいだに入っている。](assets/scenario-inserted.jpg)

作者がシナリオエディターで**保存**を押すまで、ディスクには何も書かれません。シナリオのテキストが唯一の正であり、パレットはそれを書くのを助けるだけです。

## うまくいかないとき

1. **種類や行動がない。** 読み込まれたどの MOD もスキーマで記述していません。Schemas のページに追加方法があります。
2. **MOD の一覧が空。** 書き込める MOD がありません（フォルダーとしてインストールされた MOD にだけ書け、パッケージ済みには書けません）。
3. **挿入で「シナリオが開いていない」と言われる。** 先にシナリオエディターで開くか、コピーを使ってください。
4. **フィールドがただのテキストボックス。** スキーマ上の型が text か不明です。
